\section{Metodología}

Para estudiar el movimiento oscilatorio se construyó un péndulo simple mediante un sensor de rotación NeuLog, un cordel y esferas de diferente masa. El sensor se conectó a la interfaz NeuLog correspondiente y se empleó el software NeuLog para registrar la posición angular $\theta$ en función del tiempo \cite{neulog2020}. Las mediciones ordinarias se configuraron con una duración de \SI{10}{\second} y una frecuencia de muestreo de \SI{100}{muestras\per\second}. Los datos obtenidos se exportaron en formato CSV y las gráficas correspondientes en formato PNG para su posterior procesamiento.

La Fig.~\ref{fig:montaje_pendulo} muestra el montaje experimental empleado durante la práctica, compuesto por el sensor de rotación NeuLog, el soporte, el cordel y la esfera utilizada como masa oscilante.

\subsection{Dependencia del período con la masa}

Se mantuvieron aproximadamente constantes la longitud $L$ del péndulo y la amplitud angular inicial. Bajo estas condiciones se realizaron mediciones con tres esferas de diferente masa, manteniendo el mismo procedimiento de adquisición para cada una. En cada ensayo se registró la posición angular $\theta$ en función del tiempo. Posteriormente, el período de oscilación $T$ se determinó a partir de los intervalos temporales correspondientes a ciclos completos de la señal registrada.

\subsection{Dependencia del período con la longitud}

Para analizar la influencia de la longitud, se utilizó la esfera de menor masa y se mantuvo aproximadamente constante la amplitud angular inicial. La longitud $L$ se modificó en cinco configuraciones, con variaciones cercanas a \SI{5}{\centi\meter} entre valores sucesivos. Para cada longitud se registró el movimiento angular durante \SI{10}{\second}, con una frecuencia de muestreo de \SI{100}{muestras\per\second}. A partir de cada registro se determinó el período $T$, conservándose los archivos de datos y las gráficas correspondientes para su posterior análisis.

\subsection{Dependencia del período con la amplitud}

Se empleó la esfera de menor masa y se fijó una longitud cercana a \SI{50}{\centi\meter}. Se utilizaron tres valores de amplitud angular inicial $\theta_0$ comprendidos entre $15^\circ$ y $30^\circ$. Para cada configuración se registró la posición angular en función del tiempo bajo las mismas condiciones de adquisición. El período de oscilación se determinó posteriormente a partir de los intervalos temporales asociados a ciclos completos de la señal.

\subsection{Oscilaciones amortiguadas}

Para estudiar el amortiguamiento se utilizó la esfera de menor masa y una longitud del péndulo cercana a \SI{50}{\centi\meter}. En este caso, el sensor se configuró para registrar el movimiento durante \SI{1}{\minute}, manteniendo una frecuencia de muestreo de \SI{100}{muestras\per\second}. Se registró la disminución progresiva de la amplitud angular con el tiempo y se exportaron los datos obtenidos. Posteriormente, se identificaron los máximos de amplitud angular $\theta_{\max}$ y sus respectivos instantes $t$, con el propósito de analizar la relación entre la amplitud y el tiempo.
